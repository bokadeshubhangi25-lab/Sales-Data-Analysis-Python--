# Sales Data Analysis using Python

This project analyzes sales data to identify key trends, top-performing products, and revenue patterns using Python libraries.

## Tools & Libraries Used
* Python
* Pandas (Data cleaning and manipulation)
* NumPy (Numerical operations)
* Matplotlib (Data visualization)

## Files in this Repository
* sales_analysis.ipynb: Jupyter Notebook containing the complete Python code and analysis.
* sales_data.csv: The dataset used for this analysis.
* sales_chart.png: Visual output generated from the data.
